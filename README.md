# ספירת העומר — PWA

אפליקציית ווב מתקדמת (PWA) לספירת העומר, לאנדרואיד ולאייפון. ללא שלב בנייה: ה־UI בנוי מרכיבי מערכת העיצוב (React) שנטענים ישירות בדפדפן.

## מה יש באפליקציה
- **חישוב היום:** חישוב אוטומטי של יום הספירה לפי צאת הכוכבים במיקום המשתמש, עם חמש שיטות חישוב. בין עלות השחר לצאת הכוכבים מוצג היום שבו נמצאים.
- **נוסחים:** עדות המזרח, ספרד, אשכנז, חב"ד. עם ניקוד או בלי.
- **כוונות היום, מודגשות:** הספירה, האות משם אנא בכח והמילה ממזמור למנצח.
- **למנצח בצורת המנורה:** לפי הציור המסורתי, כולל שמות אנא בכח ובשכמל"ו בצדדים.
- **מעקב:** סימון כהושלם ורישום אוטומטי של זמני קריאה וגלילה. שאלה על ימים שלא סומנו, והנחיה להמשיך בלי ברכה כשחסר יום.
- **תזכורת** בצאת הכוכבים.
- **גלילה אוטומטית:** 5 מהירויות, החלקה על הפקד, הקשה על המסך להפעלה ולעצירה.
- **הקדשות:** "הזכרתי בתפילתי", מונה מתפללים, טבלת גומלי חסד בתפילה ומשפט יומי.

## הרצה מקומית
Service worker דורש שרת, ולא פתיחה ישירה של הקובץ:
```bash
npx serve .
# או
python3 -m http.server 8080
```

## פרסום ב־GitHub Pages
Settings → Pages → Source: `Deploy from a branch` → `main` / `root`.
האפליקציה תהיה זמינה בכתובת `https://<user>.github.io/<repo>/`, ומשם אפשר "להוסיף למסך הבית".

## מבנה
| קובץ | תפקיד |
|---|---|
| `index.html` | מעטפת הדף: טוען את מערכת העיצוב, `src/logic.js` ו־`src/app.js` |
| `src/logic.js` | לוגיקה: ערים, אחסון, זמנים (צאת הכוכבים, לוח עברי), חישוב היום |
| `src/app.js` | ה־UI: מסכים בנויים מרכיבי `window.OmerDS`, הקדשות, גלילה אוטומטית, הגדרות |
| `src/shell.css` | כללי מעטפת בלבד (גוף הדף, אזורי מגן). שאר העיצוב מגיע ממערכת העיצוב |
| `ds/` | עותק של מערכת העיצוב "Omer DS" (`ds/components/bundle.js` + `bundle.css`, טוקנים ב־`ds/tokens.json`, תיעוד ב־`ds/README.md`) |
| `manifest.webmanifest` | הגדרות התקנה כאפליקציה (שם, אייקונים, RTL) |
| `sw.js` | עבודה ללא רשת אחרי הביקור הראשון |
| `icons/` | אייקונים לאנדרואיד ולאייפון |
| `docs/` | צילומי הייחוס של צורת המנורה |
| `CLAUDE.md` | הקשר מלא להמשך פיתוח ב־Claude Code |

## חשוב לדעת לפני הפקה
- **הקדשות ומשפטים:** בגרסת האב־טיפוס הם נטענים ממאגר הנתונים של claude.ai (`window.claude.use('db')`). מחוץ ל־claude.ai אזור ההקדשות מוסתר. בהפקה צריך להחליף את הקריאות ב־API של מערכת הניהול. במבנה הנתונים אין שינוי:
  - `dedications`: `purpose`, `name`, `order`, `active`
  - `quotes`: `text`, `source`, `order`, `active`
  - `stats/<id>`: `shown`, `prayed`, `more`, `undo`, `dwellSec`, `hours`

  את המונים עדיף לעדכן בשרת (increment אטומי).
- **תזכורות:** ב־PWA התזכורת פועלת רק כשהאפליקציה פתוחה. להתראות ברקע: Push API עם שרת, או עטיפה ב־Capacitor עם Local Notifications (מומלץ לחנויות).
- **מיקום:** ב־PWA המותקנת ה־GPS פועל. כשאין הרשאה, העיר נבחרת לפי אזור הזמן.
- **נתונים אישיים** (מעקב, שמות שהוזכרו) נשמרים במכשיר (localStorage).
- **כוונות אנא בכח** לפי שיטת הבן איש חי: אות ליום, וביום השביעי השם כולו.
